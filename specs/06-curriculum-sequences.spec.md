# Curriculum teaching sequences

Each topic introduces a prerequisite before combining it with another demand. Stage labels describe the thinking required. A new representation can begin with smaller numbers.

Question totals count distinct prompt variants, including quantities and sentence contexts. They do not count different rules. Narrow introductory stages deliberately use fewer than 200 questions.

Every stage includes the correct answer, worked reasoning, captioned visual steps, optional narration, replay, and manual navigation. Each topic also has a stable 200-question bank for Sprint and Arena.

## Review requirements

Assess the named goal through independent answers. Hints and mistakes remain part of the evidence. Saved skill identities stay stable. Three correct answers advance a stage; mastery reports use the separate accuracy and independence rules.

Automated checks cover every stage pool and game bank, worked-step completeness, options, and independently verified arithmetic cases. Representative desktop and mobile questions were reviewed. Classroom use is still needed to calibrate timings and difficulty. External video lessons have not been added for the new topics.
