# Teaching order for subject navigation

Arrange topic introductions in a suggested foundation-to-extension sequence. This is a navigation aid, not a grade assignment or a prerequisite lock. A topic can contain harder later levels; students may revisit earlier topics.

Use one shared order across topic selectors and adult topic lists. Group the game picker into short teaching stages. Maths moves from number foundations through everyday measurement, number relationships, proportion, spatial reasoning and applications to data/algebra. English moves from word classes to complete sentences, agreement/tense, punctuation and connected writing. Put nouns before pronouns, complete sentences before subject/predicate, subject/predicate before agreement, and punctuation before direct speech.

Preserve topic IDs, numeric skill IDs, question banks and adaptive progression. Legacy mixed grammar topics retain their identities and stay hidden in the child picker. Unknown future topics sort after known topics, never before foundations. Cover every visible topic exactly once.
